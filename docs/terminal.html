🖥️ Терминал Linux — шпаргалка по командам#

Универсальная шпаргалка для bash/zsh/fish. Обозначения: <file> — обязательный аргумент, [file] — необязательный, ... — повторяется. Большинство команд поддерживают --help и man <cmd>.

📁 Навигация по файловой системе#

Команда Действие
pwd Текущий путь (print working directory)
ls Список файлов
ls -la Подробный список + скрытые файлы
ls -lh Размеры в читаемом виде (KB/MB)
ls -lt По времени изменения
ls -R Рекурсивно (с подкаталогами)
cd <dir> Перейти в каталог
cd .. На уровень выше
cd ~ / cd Домашний каталог
cd - Вернуться в предыдущий каталог
pushd <dir> / popd Перейти с запоминанием / вернуться
tree Дерево каталогов (tree -L 2 — глубина 2)
find <dir> -name "*.py" Найти файлы по имени
fd "pattern" Быстрый поиск (нужен fd / fd-find)

Команда Действие
touch <file> Создать пустой файл / обновить время
mkdir <dir> Создать каталог
mkdir -p a/b/c Создать с родителями (без ошибок)
cp <src> <dst> Копировать
cp -r <src> <dst> Копировать рекурсивно (каталог)
mv <src> <dst> Переместить / переименовать
rm <file> Удалить файл
rm -r <dir> Удалить каталог рекурсивно
rm -rf <dir> Удалить принудительно (⚠️ безвозвратно)
ln -s <target> <link> Создать символическую ссылку
stat <file> Подробная информация о файле
file <file> Определить тип файла

Команда Действие

less <file> Постраничный просмотр (q — выход, / — поиск)
more <file> Простейший постраничный просмотр
head -n 20 <file> Первые 20 строк
tail -n 20 <file> Последние 20 строк
tail -f <file> Следить за обновлениями (логи)

🔍 Поиск#

Команда Действие
grep "pattern" <file> Поиск строк по шаблону
grep -r "pattern" <dir> Рекурсивно
grep -i "pattern" Без учёта регистра
grep -n "pattern" С номерами строк
grep -v "pattern" Инверсия (НЕ совпадает)
grep -E "a\|b" Регулярные выражения (= egrep)
ripgrep "pattern" <dir> / rg "pattern" Очень быстрый поиск

find <dir> -type f -size +10M Файлы больше 10 МБ

locate <name> Поиск по индексу (updatedb)

📦 Архивы#

Команда Действие
tar -cvf archive.tar <dir> Создать .tar
tar -xvf archive.tar Распаковать .tar
tar -czvf archive.tar.gz <dir> Создать .tar.gz (gzip)
tar -xzvf archive.tar.gz Распаковать .tar.gz
tar -cjvf archive.tar.bz2 <dir> Создать .tar.bz2 (bzip2)
tar -xjvf archive.tar.bz2 Распаковать .tar.bz2
gzip <file> / gunzip <file> Сжать / распаковать .gz
zip -r archive.zip <dir> Создать .zip
unzip archive.zip Распаковать .zip
7z a archive.7z <dir> Создать .7z (нужен p7zip)

Цифровые права chmod#

7 = rwx (read+write+exec)   6 = rw-   5 = r-x   4 = r--   0 = ---
owner / group / others
755 = rwxr-xr-x   644 = rw-r--r--   600 = rw-------

📦 Пакетные менеджеры#

Arch / CachyOS (pacman + yay)#

sudo pacman -Syu              # обновить систему
sudo pacman -S <pkg>          # установить
sudo pacman -R <pkg>          # удалить
sudo pacman -Rns <pkg>        # удалить с зависимостями и конфигами
sudo pacman -Ss <name>        # поиск в репозитории
sudo pacman -Qe               # установленные явно пакеты
sudo pacman -Qdtq             # пакеты-сироты (для удаления)
yay -S <aur-pkg>              # установка из AUR
yay -Syu                      # обновить с AUR
paru -S <aur-pkg>             # paru — альтернатива yay

Debian / Ubuntu (apt)#

sudo apt update               # обновить список пакетов
sudo apt upgrade              # обновить пакеты
sudo apt install <pkg>        # установить
sudo apt remove <pkg>         # удалить
sudo apt autoremove           # удалить неиспользуемые зависимости
apt search <name>             # поиск
dpkg -L <pkg>                 # файлы пакета

Fedora (dnf)#

sudo dnf install <pkg>
sudo dnf upgrade
sudo dnf remove <pkg>
dnf search <name>

Универсально (Flatpak / Snap)#

flatpak install flathub <app>
flatpak update
flatpak list
snap install <pkg>

💡 Полезные советы#

  1. man <cmd> — всегда под рукой; / для поиска, q — выход.
  2. tldr <cmd> — если man слишком длинный, смотрите примеры.
  3. Ctrl-r — обратный поиск по истории, лучшее, что есть в bash/zsh.
  4. !! — повтор последней команды (например sudo !!).
  5. cd - — прыгнуть туда-обратно между двумя каталогами.
  6. pushd / popd — стек каталогов, удобно в скриптах.
  7. tail -f /var/log/... — следить за логом в реальном времени.
  8. xargs — передать вывод как аргументы, но осторожно с пробелами (используйте -0 вместе с find -print0).
  9. Кавычки: одинарные '...' — без подстановки, двойные "..." — с раскрытием переменных и команд, обратные \cmd`— то же, что$(cmd)`.
  10. Не делайте rm -rf / — это не шутка, проверяйте пути дважды.
  11. chmod +x script.sh перед запуском скрипта ./script.sh.
  12. Переменная PATH — где shell ищет команды: echo $PATH, добавить: export PATH="$PATH:/new/dir".

Сгенерировано как шпаргалка. Команды могут отличаться в зависимости от дистрибутива — проверяйте через <cmd> --help или man <cmd>.
