📦 Yazi — шпаргалка по горячим клавишам#

Yazi — быстрый терминальный файловый менеджер на Rust. Полная справка внутри программы: ? Дом: https://yazi-rs.github.io

🐚 Интеграция с оболочкой (shell wrapper yy)#

Yazi умеет менять текущий каталог оболочки при выходе. Для этого нужно добавить функцию-обёртку.

Bash (~/.bashrc)#

function yy() {
    local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
    yazi "$@" --cwd-file="$tmp"
    if cwd="$(command cat -- "$tmp")" && [ -n "$cwd" ] && [ "$cwd" != "$PWD" ]; then
        builtin cd -- "$cwd"
    fi
    rm -f -- "$tmp"
}

Zsh (~/.zshrc)#

function yy() {
    local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
    yazi "$@" --cwd-file="$tmp"
    if cwd="$(command cat -- "$tmp")" && [ -n "$cwd" ] && [ "$cwd" != "$PWD" ]; then
        builtin cd -- "$cwd"
    fi
    rm -f -- "$tmp"
}

Fish (~/.config/fish/functions/y.fish)#

function y
    set tmp (mktemp -t "yazi-cwd.XXXXXX")
    yazi $argv --cwd-file="$tmp"
    read -z cwd < "$tmp"
    if test -n "$cwd" -a "$cwd" != "$PWD"
        builtin cd "$cwd"
    end
    rm -f "$tmp"
end

Nushell (~/.config/nushell/config.nu или env.nu)#

def --env yy [...args] {
    let tmp = (mktemp -t "yazi-cwd.XXXXXX")
    yazi ...$args --cwd-file $tmp
    let cwd = (open $tmp)
    if $cwd != "" and $cwd != $env.PWD {
        cd $cwd
    }
    rm -fp $tmp
}

После запускаете yy вместо yazi — и при выходе shell перейдёт в каталог, где вы закончили.

⚙️ Конфигурация#

Расположение файлов конфигурации: ~/.config/yazi/

Файл Назначение
yazi.toml Основные настройки (поведение, плагины, opener’ы)
keymap.toml Горячие клавиши (переопределение биндингов)
theme.toml Тема оформления / цвета
init.lua Lua-инициализация (хуки, кастомные команды)

Пример своего биндинга в keymap.toml:

[manager]
prepend_keymap = [
    # открыть выделенное в Neovim
    { on = [ "T" ], run = "shell 'nvim \"$@\"' --confirm", desc = "Open in nvim" },
    # открыть выделенное в VS Code
    { on = [ "C" ], run = "shell 'code \"$@\"' --confirm", desc = "Open in VS Code" },
]

💡 Полезные советы#

  1. ? — ваш главный помощник: показывает биндинги для текущего контекста (manager, tasks, select, input, help).
  2. Массовые действия: выделите файлы через Space, затем y/x/d/p.
  3. Быстрый переход: z (zoxide) по частотным каталогам.
  4. Превью: yazi умеет показывать изображения, PDF, видео-кадры, исходники с подсветкой. Нужны chafa/ueberzugpp для картинок, ffmpeg для видео.
  5. Плагины: см. https://yazi-rs.github.io/docs/plugins
  6. Обновление темы/конфига на лету: внутри yazi :ya sync (или просто перезапустите).
  7. Открыть терминал в текущем каталоге: добавьте в keymap.toml биндинг shell '$SHELL' --block --confirm.

Сгенерировано как шпаргалка. Версия может отличаться — проверяйте через ? в yazi.
