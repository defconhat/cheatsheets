# 🚀 Warp — шпаргалка

> **Warp** — терминал на Rust с GPU-рендерингом, IDE-фичами и встроенным AI.
> Блоки (Blocks), автодополнение, команда-как-текст, воркфлоу. Дом: https://www.warp.dev

---

## 📦 Установка

```bash
# Arch / CachyOS (AUR)
yay -S warp-terminal
paru -S warp-terminal

# macOS
brew install --cask warp

# Linux (.deb / .rpm / .pkg)
# скачать с https://www.warp.dev/downloads

# Windows
# скачать .exe с https://www.warp.dev/downloads
```

> Warp бесплатен с обязательной авторизацией (Google/GitHub). Есть **Warp Drive** (синхронизация) и **Warp AI** (платная подписка для команд).

## 🎨 Ключевые концепции

| Концепт | Что это |
|---|---|
| **Block (блок)** | Один ввод-вывод команды с заголовком и контекстом. Как «ячейка» в ноутбуке. |
| **Workflows** | Переиспользуемые параметризованные команды (как функции). |
| **Command Palette** | Поиск любой команды/настройки (как в VS Code). |
| **Warp AI / Agent Mode** | Встроенный ИИ-ассистент для генерации/объяснения команд. |
| **Warp Drive** | Облачная синхронизация настроек, истории, workflows. |

## ⌨️ Горячие клавиши

|---|---|

| `Ctrl+Space` | Принять автодополнение целиком |

| `Ctrl+_` | Отменить (undo) в строке ввода |

| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующая / предыдущая вкладка |

## 🤖 AI (Agent Mode)

Warp имеет встроенный ИИ — можно генерировать команды из текста, объяснять ошибки, рефакторить скрипты.

### Использование
1. Нажать `#` в строке ввода → режим промпта к ИИ.
2. Описать, что нужно: «найти все .log файлы крупнее 100MB».
3. ИИ предложит команду, можно отредактировать перед выполнением.
4. `Ctrl+Shift+A` — полноценный Agent Mode (итеративный диалог).

### Полезные промпты
```text
# найди все файлы .py, изменённые за последнюю неделю
# объясни ошибку последней команды
# сделай oneliner: посчитать кол-во строк во всех .csv
# сгенерируй ssh-туннель к user@bastion с пробросом 5432
```

### Объяснение ошибок
При падении команды — кликнуть на блок → **«Explain this error»** / иконка ✨. ИИ объяснит причину и предложит фикс.

## 🔄 Workflows (ваш «.bashrc на стероидах»)

Workflow — параметризованный шаблон команды, доступный по имени.

### Создание
1. Выполнить команду → кликнуть на блок → **«Save as Workflow»**.
2. Или: Settings → Workflows → New.

### Пример `.warp/workflows/deploy-github.yml`
```yaml
name: deploy-github
command: |-
  gh release create {{tag}} dist/* --notes "{{notes}}"
tags: [git, release]
description: Создать GitHub Release и залить артефакты
arguments:
  - name: tag
    description: Версия релиза (напр. v1.2.3)
    default_value: latest
  - name: notes
    description: Описание релиза
```

### Вызов
- `Ctrl+\` → выбрать из списка, либо
- Начать вводить имя → подстановка с полями для параметров.

Workflows хранятся в:
- `~/.warp/workflows/` (глобально)
- `<repo>/.warp/workflows/` (для проекта, можно коммитить)

## 🎨 Оформление (Themes)

- **Settings → Appearance**.
- Светлые/тёмные темы, кастомные пресеты.
- Поддержка **Nerd Fonts** (для иконок в shell-prompt).
- GPU-рендеринг = плавный скролл даже на 100k строк.

### Шрифты
Рекомендуются: JetBrainsMono Nerd Font, FiraCode Nerd Font, MesloLGS NF (для p10k).

## 🔍 Поиск и история

| Что | Как |
|---|---|
| Инкрементальный поиск истории | `Ctrl+R` |
| Поиск по выводу блока | кликнуть блок → `Ctrl+F` |
| Фильтр команд по подстроке | `Ctrl+R` + ввод |
| Скопировать весь вывод блока | клик на блок → `Cmd+C` / иконка 📋 |
| Поделиться блоком (ссылка) | блок → «Share» (через Warp Drive) |

### История
- Сохраняется локально + опционально в Warp Drive (синхрон между машинами).
- Можно искать по дате/команде/директории.

## 🖥️ Sessions / Projects

- **Project** — привязка к папке с настройками: env-переменные, tabs, workflows.
- При открытии проекта восстанавливаются вкладки и переменные.
- Settings → Projects → добавить папку → задать env.

```bash
# Пример .warp/projects/myapp.toml (упрощённо)
[project]
name = "myapp"
path = "~/code/myapp"
windows = []
env = { DATABASE_URL = "postgres://localhost/myapp" }
```

## 🧩 Сочетания с другими инструментами

### starship / powerlevel10k
Warp совместим с любым shell-prompt — просто настрой как обычно в `~/.zshrc` / `~/.bashrc`.

### tmux
Можно использовать внутри Warp. Блоки Warp и сплиты tmux — ортогональны.

### zsh / bash / fish
Warp поддерживает любой шелл. Автодополнение и блоки работают везде.

## 💡 Частые сценарии

### Сгенерировать сложную команду через ИИ
```
# найти все docker-контейнеры старше 7 дней и остановить
```
Warp предложит что-то вроде:
```bash
docker ps -a --filter "status=running" --format '{{.Names}}' \
  | xargs -I{} docker stop {}
```

### Скопировать путь из блока
Клик по блоку → `Cmd+C` копирует **весь вывод**. Для части вывода — выделить мышкой.

### Поделиться логом с коллегой
Блок → «Share to Warp» → ссылка (через Warp Drive).

### Переиспользовать длинную команду
Сохранить как workflow (`Ctrl+\` → New) → вызывать по имени + параметры.

## ⚠️ Минусы и нюансы

| Минус | Комментарий |
|---|---|
| **Требует логин** | Без аккаунта не запускается (бесплатный) |
| **Проприетарный** | Открыто не ядро, только workflows/themes |
| **Память** | Rust + GPU, но тяжелее `kitty` / `alacritty` |
| **Wayland** | Поддержка улучшается, но на Linux есть шероховатости |
| **Warp AI платно** | Без подписки — ограниченный режим |

## 🆚 Warp vs альтернативы

| Терминал | Плюсы | Минусы |
|---|---|---|
| **Warp** | Блоки, AI, workflows, GPU | Логин, закрытый код |
| **Kitty** | Лёгкий, GPU, тайлинг, скрипты | Нет AI из коробки |
| **Alacritty** | Очень быстрый, минималистичный | Нет фич (вкладок, сплитов) |
| **WezTerm** | Мощный Lua-конфиг, мульти-платформа | Сложнее настройка |
| **GNOME Terminal / Konsole** | Дефолт, простые | Медленные, без AI |
| **iTerm2** | (mac) де-факто стандарт | Только macOS |
